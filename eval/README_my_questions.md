# 自建评测题集 `my_questions.jsonl`

公开题库（`public_questions.jsonl`）之外的补充题。作业第四关要求
「你自己的评测题：公开题库之外，你觉得还该测什么，补进去」——
这份就是那一项。

7 题 / 14 分。跑法：

```bash
# 服务先跑起来（另开一个终端 make run）
cd starter && make eval-mine
```

## 为什么是这几题

公开题库 55 题全过之后，我拿**自然口语**去问，连着问出了四个 bug：

| 我问的 | 当时的回答 | 问题 |
|---|---|---|
| 三文鱼销量怎么样？ | 销量 27262 件（**全公司**） | 口语商品名「三文鱼」没被认成 三文鱼poke，限定丢了 |
| 谁家的三文鱼最好吃 | 甩出一份停售通知 | 口味是主观评价，知识库答不了，该说不知道 |
| 适不适合外出？ | 甩出《指标口径手册》 | 要不要出门取决于天气，系统无从观察 |
| 三文鱼怎么样？ | 反问"这句像是追问，但没有上文" | 明明点了商品，是能直接答的 |

这四条的共同点是：**公开题库的满分掩盖不了它们** —— 题目问法是书面语、
限定词齐全，所以没暴露。所以我把它们原样收进题集，作为回归防线。

第 8 条我**没有收进来**：「会员储值能在外卖平台用吗？」现在仍答成支付占比，
根因与「会员的优惠」相同 —— KB-011《会员储值政策》全文没有「优惠」二字，
而 FAQ 正文同时含「会员」和「优惠」，按词命中必然偏向 FAQ。
这是个**未决的词汇缺口**（补 KB-003 别名词典还是不补），
没定之前我不想把它写进题集假装已覆盖。已记在 README 的「已知限制」里。

## 题目与判据

| ID | 分类 | 问句 | 判据要点 |
|---|---|---|---|
| X01 | data | 三文鱼销量怎么样？ | 必须是 `data`、出现 `1567`、**不许出现 27262**（修复前的全公司总额） |
| X02 | refusal | 谁家的三文鱼最好吃 | 必须 `refusal`、不许引用任何文档 |
| X03 | refusal | 适不适合外出？ | 必须 `refusal`、不许引用任何文档 |
| X04 | doc | 三文鱼怎么样？ | 必须是 `doc`/`hybrid`、引用 KB-021、提到「停售」 |
| X05 | doc | 这个活动适不适合在 S02 做？ | **边界题**：带「适不适合」但是正经业务问题，不能被 X03 那个修复误伤 |
| X06 | data | 包包店七月营业额是多少？ | 口语门店名要落到 S03、出现 `29821` |
| X07 | data | JBB 六月卖了多少钱？ | 英文缩写门店名要落到 S03、出现 `23967` |

期望值没有一个是我猜的：每一条都是先把问句跑到服务上、看实际返回，
再回到知识与数据里核对过（例如 S03 七月净营业额 29821.00，
与 `/api/metrics/summary` 对得上），然后才写进判据。

## 它在修复前确实是红的

这是这份题集有没有价值的关键。我在**回滚修复之前**跑了一遍：

```
修复前：总分 6.00 / 14.00
  X01   0.00 / 2.00   ← 红
  X02   0.00 / 2.00   ← 红
  X03   0.00 / 2.00   ← 红
  X04   0.00 / 2.00   ← 红
  X05   2.00 / 2.00
  X06   2.00 / 2.00
  X07   2.00 / 2.00

修复后：总分 14.00 / 14.00
```

`X01`–`X04`（8 分）**在修复前就是红的**，说明它们守的是真修过的缺陷。
`X05`–`X07`（6 分）修复前就是绿的 —— 它们不是修复题，而是**边界与防回归题**：
`X05` 专门守着 `X03` 那个修复的"误伤半径"（我给 `CANNOT_KNOW` 加的是
`外出/带伞/冷不冷` 这类词，而不是裸的「适不适合」），
`X06`/`X07` 守着门店别名词典（口语名 / 英文缩写）不被后续改动弄坏。

## 已知不覆盖的

- **跨会话隔离**（不同 `session_id` 不能串线）跑不出来：评测脚本是在一个
  `session_id` 里依次发多个 turn 的，表达不了"两个会话交叉问"。
  这条由 `tests/test_multi_turn.py` 的单元测试覆盖。
- **`/api/retrieve` 的排序正确性**：那是检索质量，公开题库已有 15 题。
- **上面说的第 8 条**（会员类问句）。
